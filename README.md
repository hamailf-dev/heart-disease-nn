# Heart Disease Prediction using Neural Network

A deep learning project to predict heart disease using the UCI Heart Disease dataset. Built with TensorFlow/Keras.

## 📊 Results
- **Test Accuracy**: 71.74%
- **Training Accuracy**: 72.22%
- **Loss**: 0.56
